## 🌄 Abora OS

**[Abora OS](https://github.com/AnimatedGTVR/Abora-OS)** is my main project — a NixOS-based distro for people who want the good parts of NixOS without having to fight it before they even reach the desktop.

**Current release: v4.1 “Horizon”**

```text
23 desktop profiles
Stable + Edge channels
ANIX
Abora Gaming
Abora Labs
custom installer + tooling
NixOS underneath all of it
```

Horizon is mostly about making the stuff already there actually behave: installer reliability, updates, rollback, diagnostics, hardware setup, and a pile of fixes that somehow kept multiplying.
