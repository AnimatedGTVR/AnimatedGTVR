## 👋 Hey

I'm **Animated**.

I spend most of my time building Linux distributions, experimenting with desktop environments, writing music, and creating projects that probably started out much smaller than they ended up becoming.

I started out making games and VR projects, but these days I'm mostly focused on **operating systems, Linux tooling, package management, programming languages, and open-source software**.

---

## 🌄 Abora OS

My main project is **[Abora OS](https://github.com/AnimatedGTVR/Abora-OS)** — a NixOS-based Linux distribution designed to make NixOS easier to install, use, and understand without giving up reproducibility, declarative configuration, or rollbacks.

**Current release:** Abora OS **v4.1 “Horizon”**

- 🧊 NixOS based
- 🖥️ 23 desktop profiles
- 🧰 ANIX system tooling
- 🎮 Optional Abora Gaming layer
- 🧪 Abora Labs
- 🔁 Stable + Edge release channels
- 🛠️ Custom installer and system utilities
