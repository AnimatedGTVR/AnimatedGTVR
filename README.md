## Abora OS

<div align="center">

<img src="https://raw.githubusercontent.com/AnimatedGTVR/Abora-OS/edge/assets/Images/v4.1-horizon-banner.png" width="900" alt="Abora OS v4.1 Horizon" />

</div>

**[Abora OS](https://github.com/AnimatedGTVR/Abora-OS)** is a NixOS-based Linux distribution built around making NixOS easier to install, use, and understand.

### v4.1 — Horizon

Horizon is the current release, with most of the work focused on reliability and making the existing system better to use.

- safer installer
- non-destructive installation
- improved update and rollback paths
- better diagnostics
- GPU setup for NVIDIA, AMD, and Intel
- ANIX v2
- Abora Gaming
- Abora Labs
- 23 desktop profiles
- Stable and Edge channels
